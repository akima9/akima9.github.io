## Kotlin의 배열

### 배열이란 무엇인가요?
태양광 패널을 모아 놓은 것을 솔라 배열(solar array)이라고 부르듯이 배열은 하나 이상의 값을 나타냅니다. 배열은 모든 값이 동일한 데이터 타입을 가지는 값들의 순서입니다.

![Array](https://developer.android.com/static/codelabs/basic-android-kotlin-compose-collections/img/33986e4256650b8b_1440.png?hl=ko)

- 배열에는 요소(elements) 또는 항목(items)이라고 불리는 여러 값이 포함됩니다.
- 배열의 요소들은 순서가 있으며, 색인(index)을 사용해 접근할 수 있습니다.

색인(index)란 무엇일까요? 색인은 배열 내 요소에 대응하는 정수입니다. 배열의 첫 번째 요소는 색인 0에 위치하고, 두 번째 요소는 첫 번째 요소로부터 한 칸 떨어져 있으므로 색인 1, 세 번째 요소는 색인 2와 같이 이어집니다. 색인은 배열에서 특정 요소가 시작 요소로부터 얼마나 떨어져 있는지를 알려줍니다. 이를 제로 인덱싱이라고 부릅니다.

![Index](https://developer.android.com/static/codelabs/basic-android-kotlin-compose-collections/img/bb77ec7506ac1a26_1440.png?hl=ko)

기기 메모리(RAM)에서는 배열의 요소가 서로 나란히 저장됩니다. 이것은 두 가지 중요한 의미가 있습니다.

- 색인을 통해 배열 요소에 빠르게 액세스할 수 있습니다.
- 배열의 크기는 고정되어 있습니다. 즉, 정해진 크기를 초과하여 배열에 요소를 추가할 수는 없습니다. 그러나 배열의 색인에서 값은 수정할 수 있습니다.

코드에서 배열을 선언하려면 `arrayOf()` 함수를 사용하세요.

![arrayOf](https://developer.android.com/static/codelabs/basic-android-kotlin-compose-collections/img/69e283b32d35f799_1440.png?hl=ko)

`arrayOf()` 함수는 배열 요소를 매개변수로 사용하고 전달된 매개변수와 일치하는 유형의 배열을 반환합니다.

태양계를 간단히 탐사하여 실제 배열을 살펴보겠습니다.

<a href="https://developer.android.com/training/kotlinplayground?hl=ko" target="_blank">Kotlin 플레이그라운드</a>로 이동합니다.

`main()`에서 `rockPlanets` 변수를 만듭니다. `arrayOf()` 함수를 호출하여 네 가지 문자열과 함께 `String` 유형을 전달합니다.
```kotlin
val rockPlanets = arrayOf<String>("Mercury", "Venus", "Earth", "Mars")
```

Kotlin은 유형 추론을 사용하므로 `arrayOf()` 함수를 호출할 때 유형 이름을 생략해도 됩니다. `gasPlanets`를 추가합니다.
```kotlin
val gasPlanets = arrayOf("Jupiter", "Saturn", "Uranus", "Neptune")
```

`solarSystem`이라는 새 변수를 만들고, `rockPlanets`와 `gasPlanets` 배열을 `+`연산자로 합쳐서 할당해 보세요. 그 결과는 모든 요소를 포함하는 새로운 배열이 됩니다.
```kotlin
val solarSystem = rockPlanets + gasPlanets
```

### 배열 요소에 액세스
색인으로 배열 요소에 액세스할 수 있습니다.

![access](https://developer.android.com/static/codelabs/basic-android-kotlin-compose-collections/img/1f8398eaee30c7b0_1440.png?hl=ko)

`main()`에서 `solarSystem` 배열의 각 요소에 액세스하여 출력합니다.
```kotlin
println(solarSystem[0])
println(solarSystem[1])
println(solarSystem[2])
println(solarSystem[3])
println(solarSystem[4])
println(solarSystem[5])
println(solarSystem[6])
println(solarSystem[7])
```

프로그램을 실행합니다. 요소의 순서는 `arrayOf()` 함수를 호출할 때 나열한 순서와 같습니다.
```
Mercury
Venus
Earth
Mars
Jupiter
Saturn
Uranus
Neptune
```

배열 요소의 값을 색인으로 설정할 수도 있습니다.

![값설정](https://developer.android.com/static/codelabs/basic-android-kotlin-compose-collections/img/9469e321ed79c074_1440.png?hl=ko)

`solarSystem` 배열의 값을 수정하는 방법을 연습해 보겠습니다.

색인 3의 요소에 액세스하여 `"Little Earth"`와 같게 설정합니다.
```kotlin
fun main() {
    val rockPlanets = arrayOf<String>("Mercury", "Venus", "Earth", "Mars")
    val gasPlanets = arrayOf("Jupiter", "Saturn", "Uranus", "Neptune")
    val solarSystem = rockPlanets + gasPlanets
    
    solarSystem[3] = "Little Earth"
    
    println(solarSystem[0])
    println(solarSystem[1])
    println(solarSystem[2])
    println(solarSystem[3])
    println(solarSystem[4])
    println(solarSystem[5])
    println(solarSystem[6])
    println(solarSystem[7])
}
```

프로그램을 실행합니다. 배열의 네 번째 요소가 업데이트됩니다.
```
Mercury
Venus
Earth
Little Earth
Jupiter
Saturn
Uranus
Neptune
```

색인 8에 Pluto를 추가합니다.
```kotlin
solarSystem[8] = "Pluto"
```

코드를 실행합니다.
```
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 8 out of bounds for length 8
```

`ArrayIndexOutOfBounds` 예외가 발생합니다. 배열에 이미 요소 8개가 있으므로 당연히 9번째 요소는 추가할 수 없습니다. 배열에 추가한 Pluto를 삭제합니다.
```kotlin
//코드 삭제
solarSystem[8] = "Pluto"
```

배열을 지금보다 크게 만들려면 새 배열을 만들어야 합니다. `newSolarSystem`이라는 새 변수를 정의합니다.
```kotlin
val newSolarSystem = arrayOf("Mercury", "Venus", "Earth", "Mars", "Jupiter", "Saturn", "Uranus", "Neptune", "Pluto")
```

이제 색인 8에 있는 요소를 출력해 봅니다.
```kotlin
println(newSolarSystem[8])
```

코드를 실행합니다.
```
...
Pluto
```

## List
리스트는 순서가 있는 확장 가능한 컬렉션으로, 일반적으로 크기를 조절할 수 있는 배열로 구현됩니다. 배열의 용량이 꽉 찬 상태에서 새 요소를 삽입하려고 하면, 기존 배열이 더 큰 배열로 복사되어 저장됩니다.

![리스트](https://developer.android.com/static/codelabs/basic-android-kotlin-compose-collections/img/a4970d42cd1d2b66_1440.png?hl=ko)

리스트를 사용하면 특정 색인의 다른 요소 사이에 새 요소를 삽입할 수도 있습니다.

![삽입](https://developer.android.com/static/codelabs/basic-android-kotlin-compose-collections/img/a678d6a41e6afd46_1440.png?hl=ko)

리스트는 이런 방식을 통해 요소를 추가하고 삭제할 수 있습니다. 리스트에 요소를 추가하는 데 걸리는 시간은 리스트의 크기와 상관없이 거의 일정합니다. 그러나 아주 가끔 새로운 요소를 추가하면 리스트 내부의 배열 크기를 초과하게 되는 상황이 발생할 수 있습니다. 이때는 기존 요소들이 새로운 더 큰 배열로 복사되어야 합니다. 리스트는 이런 작업을 내부적으로 자동 처리해주지만, 결국 리스트의 내부 구조는 필요할 때 교체되는 배열 기반이라는 점은 변하지 않습니다.

### `List` 및 `MutableList`
- `List`는 순서가 지정된 읽기 전용 항목 컬렉션과 관련된 속성과 메서드를 정의하는 인터페이스입니다.
- `MutableList`는 요소 추가 및 삭제와 같이 리스트를 수정하는 메서드를 정의하여 `List` 인터페이스를 확장합니다.

### `listOf()` 함수
`arrayOf()` 함수와 마찬가지로 `listOf()` 함수는 항목을 매개변수로 사용하지만 배열이 아닌 `List`를 반환합니다.

`main()`에서 기존 코드를 삭제합니다. `listOf()` 함수를 호출하여 `solarSystem`이라는 행성 `List`를 만듭니다.
```kotlin
fun main() {
    val solarSystem = listOf("Mercury", "Venus", "Earth", "Mars", "Jupiter", "Saturn", "Uranus", "Neptune")
}
```

`List`에는 리스트에 있는 요소의 수를 가져오는 `size` 속성이 있습니다.
```kotlin
fun main() {
    val solarSystem = listOf("Mercury", "Venus", "Earth", "Mars", "Jupiter", "Saturn", "Uranus", "Neptune")

    println(solarSystem.size)
}
```

코드를 실행합니다.
```
8
```

### 리스트의 요소에 액세스
배열과 마찬가지로 리스트의 특정 인덱스에 있는 요소는 대괄호 문법을 사용해 접근할 수 있습니다. 동일한 기능을 수행하는 `get()` 메서드를 사용할 수도 있습니다. 대괄호 문법과 `get()` 메서드는 `Int`를 매개변수로 받아, 해당 인덱스의 요소를 반환합니다.

대괄호 문법을 사용하여 인덱스 2의 행성을 출력합니다.
```kotlin
println(solarSystem[2])
```

`get()`을 호출하여 인덱스 3의 요소를 출력합니다.
```kotlin
println(solarSystem.get(3))
```

코드를 실행합니다.
```
...
Earth
Mars
```

인덱스로 요소를 가져오는 것 외에도 `indexOf()` 메서드를 사용하여 특정 요소의 인덱스를 검색할 수도 있습니다. `indexOf()` 메서드는 인수로 전달되는 요소를 리스트에서 검색하여 처음으로 일치하는 요소의 인덱스를 반환합니다. 리스트에 요소가 없으면 `-1`이 반환됩니다.

`solarSystem` 리스트에서 `indexOf()` 메서드를 호출하여 `"Earth"`를 전달하는 결과를 출력합니다.
```kotlin
println(solarSystem.indexOf("Earth"))
```

`indexOf()` 메서드를 호출하여 `"Pluto"`를 전달하고 그 결과를 출력합니다.
```kotlin
println(solarSystem.indexOf("Pluto"))
```

코드를 실행합니다.
```
...
2
-1
```

### `for` 루프를 사용하여 리스트 요소 반복
![for문](https://developer.android.com/static/codelabs/basic-android-kotlin-compose-collections/img/f11277e6af4459bb_1440.png?hl=ko)

`in` 키워드 앞에 있는 변수는 `val` 또는 `var`로 선언되지 않으며 get-only로 간주됩니다. 리스트에 복수형 이름이 부여되면 변수 이름은 일반적으로 단수형으로 지정됩니다. 변수 이름을 `item` 또는 `element`로 지정하는 것도 일반적입니다. 이는 컬렉션의 현재 요소에 상응하는 임시 변수로 사용되며 중괄호 내에서 액세스할 수 있습니다.

`for` 루프를 사용하여 각 행성 이름을 별도의 줄에 출력합니다.
```kotlin
for (planet in solarSystem) {
    println(planet)
}
```

코드를 실행합니다.
```
...
Mercury
Venus
Earth
Mars
Jupiter
Saturn
Uranus
Neptune
```

### 리스트에 요소 추가
컬렉션의 요소를 추가, 삭제, 업데이트하는 기능은 `MutableList` 인터페이스를 구현하는 클래스에서만 사용할 수 있습니다. 요소를 추가하거나 삭제하려는 리스트를 만들 때 `listOf()` 대신 `mutableListOf()` 함수를 구체적으로 호출해야 합니다.

`add()` 함수에는 두 가지 버전이 있습니다.
- 첫 번째 `add()` 함수는 리스트에 있는 요소 유형의 단일 매개변수를 보유하고 이를 리스트 끝에 추가합니다.
- 다른 버전의 `add()`에는 매개변수가 두 개 있습니다. 첫 번째 매개변수는 새 요소를 삽입해야 하는 인덱스에 해당합니다. 두 번째 매개변수는 리스트에 추가되는 요소입니다.

`listOf()` 대신 `mutableListOf()`을 호출하도록 `solarSystem`의 초기화를 변경합니다.
```kotlin
val solarSystem = mutableListOf("Mercury", "Venus", "Earth", "Mars", "Jupiter", "Saturn", "Uranus", "Neptune")
```

`solarSystem`에서 `add()` 메서드를 호출하여 `"Pluto"`를 단일 인수로 전달합니다.
```kotlin
solarSystem.add("Pluto")
```

`"Earth"`와 `"Mars"` 사이의 인덱스 3에 `"Theia"`를 삽입합니다.
```kotlin
solarSystem.add(3, "Theia")
```

### 특정 인덱스의 요소 업데이트
대괄호 문법을 사용하여 기존 요소를 업데이트할 수 있습니다.

인덱스 3의 값을 `"Future Moon"`으로 업데이트합니다.
```kotlin
solarSystem[3] = "Future Moon"
```

### 리스트에서 요소 삭제
`remove()` 메서드에 요소를 전달하거나 `removeAt()`을 사용하여 인덱스로 요소를 삭제할 수 있습니다.
